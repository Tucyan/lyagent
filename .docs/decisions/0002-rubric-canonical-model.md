# ADR-0002：评分表的冻结格式与计分模式

- 状态：Accepted
- 日期：2026-08-03

## 背景

评分表需要供教师预览和修改，也必须供后续批改程序稳定校验、计算、哈希和版本化。仅用Markdown或CSV不能无歧义地表达等级区间、重叠规则和混合计分。

## 决策

冻结评分表以经Zod校验的结构化JSON为唯一事实来源。Markdown由该JSON即时渲染和导出；CSV不作为评分表格式。顶层计分模式为加分制、减分制和混合制；混合制按主体评分加奖励减扣分，并将结果限制在0到总分。

## 影响

Schema和Service负责确定性校验、分数计算、版本和哈希；Agent只生成或修改结构化草稿。冻结版本不可修改，历史版本只能复制成新草稿。后续批改必须选择冻结JSON版本。

## 重新评估条件

若需要支持无法由这三种计分公式表达且必须由程序直接计算的制度，或评分表需要与外部系统进行双向原生编辑时，重新评估该模型。
