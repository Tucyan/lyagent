# Course Agent 试用与部署使用说明（Windows 环境）

本指南面向首次试用与离线部署 Course Agent 的教师与运维人员，提供从发布包解压到完成作业批改和成绩导出的完整全流程操作指引。

---

## 1. 运行前准备与安全边界

### 1.1 系统要求
- **操作系统**：Windows 10 / 11 64 位（x64 架构）。
- **解压工具**：已安装 WinRAR（默认路径 `C:\Program Files\WinRAR\WinRAR.exe`）。
- **网络需求**：
  - 若使用本地/离线大模型或本地环回代理，无需外网访问；
  - 若使用公网大模型（如通义千问 Qwen 或 OpenAI 兼容接口），需保持对应 HTTPS 地址连通；
  - 敏感学生正文与 API Key 均存储在受控本地目录，不向未经授权的第三方泄漏。

### 1.2 发布包校验
当前官方经过完整验证的 Windows 离线发布包为 **full** 包（内置 Node.js 运行时及 Docling 本地转换服务依赖）。

- **安装包文件名**：`course-agent-v0.1.0-win-x64-full.zip`
- **预期 SHA-256 哈希值**：
  ```text
  863f6e7010baf41ea0e5fdf9a5845ae20c7446550a490003be32d46d24429348
  ```

在 PowerShell 中执行哈希校验：
```powershell
Get-FileHash -Algorithm SHA256 "path\to\course-agent-v0.1.0-win-x64-full.zip"
```
> [!IMPORTANT]
> 解压前必须核对 SHA-256 哈希值。哈希不匹配时不得继续，更不得覆盖校验值。历史 slim 包哈希不匹配，不得作为可靠发布包使用。

## 2. 规范解压与启动流程

### 2.1 WinRAR 规范解压
按照项目工程规则，为避免文件被部分覆盖或长命令意外中断，**必须解压到不存在的全新目录**。

在 PowerShell 中启动 WinRAR 解压（示例）：
```powershell
$targetDir = "C:\CourseAgent-v0.1.0"
Start-Process "C:\Program Files\WinRAR\WinRAR.exe" -ArgumentList "x -y -ibck -cfg- `"path\to\course-agent-v0.1.0-win-x64-full.zip`" `"$targetDir\`"" -Wait
```
- WinRAR 会在后台执行解压，解压完成后退出码为 0。
- 若解压出现超时或异常，该目录为不完整目录，请删除后联系管理员或由人工使用 WinRAR 图形界面解压。

### 2.2 启动服务
解压完成后，进入解压目录根目录，双击运行启动批处理文件：
```text
start.bat
```
或在终端中运行：
```powershell
.\start.bat
```

控制台窗口将按顺序执行：
1. 检测并启动本地 Docling 文档转换服务子进程；
2. 启动 Course Agent 后端与前端静态托管服务；
3. 输出本地服务访问地址（默认 `http://127.0.0.1:3000` 或启动器分配的端口）；
4. 自动通过默认系统浏览器打开工作台界面。

> [!NOTE]
> 请保持该黑底控制台窗口在后台运行，切勿关闭。

## 3. 首次配置：模型设置

首次启动或尚未配置模型时，系统会自动重定向至 **首次设置**（`/setup`）页面：

1. **主模型（必填）**：
   - **模型供应商**：支持 `Qwen（Chat Completions）` 或 `OpenAI（按 URL 自动识别）`；
   - **模型 ID**：输入部署的模型标识（如 `qwen-plus`、`qwen-turbo` 或自建模型名称）；
   - **Base URL**：填写大模型服务的接入地址（必须为 HTTPS 地址，或本机环回 `http://127.0.0.1:...`）；
   - **API Key**：填写对应的访问凭证（系统会加密存储在本地安全配置文件中，不在日志中回显）。
2. **视觉模型（可选）**：
   - 如需批改包含复杂插图、流程图或扫描手写体的报告，勾选“启用视觉模型”；
   - 可选择“复用主模型的 Base URL 与 API Key”，或单独配置独立的多模态大模型。
3. **测试连接与保存**：
   - 点击 **“测试连接”**，系统会调用小规模连通性探测接口；
   - 提示“连接测试成功”后，点击 **“保存设置”**。系统将安全更新运行时配置并自动跳转到教师工作台总览页。

## 4. 业务全流程使用操作

### 4.1 管理课程资料（知识库）
1. 从左侧导航进入 **“课程资料库”**；
2. 点击 **“新建课程”**，输入课程名称（例如：`现代操作系统原理`）；
3. 进入该课程，点击 **“导入资料”**，选择课件目录或 Markdown 资料文件；
4. 系统会自动整理并展示为知识草稿；教师可在右侧预览正文；
5. 确认无误后点击 **“发布并启用”**，生成首个不可变知识版本（v1）。
> 只有发布了知识版本的课程，才能开启课程答疑功能；若尚未发布，答疑页面会清晰展示黄底中文指引，避免误操作。

### 4.2 课程答疑
1. 点击左侧导航 **“课程答疑”**；
2. 选择已发布资料的课程，点击 **“+ 新建对话”**；
3. 在底部输入框提问（例如：“本课程大作业的评分要求包括哪些？”）；
4. Agent 将严格依据当前已发布的资料知识库检索回答，并在回答下方展示依据引用来源；
5. 若问题超出资料库范围，Agent 会诚实提示依据不足，不生成未经核实的幻觉内容。

### 4.3 制定与冻结评分表
1. 从左侧导航进入 **“评分量表”**；
2. 点击 **“+ 新建评分表”**，选择所属课程，输入作业名称与满分（如 10 分或 100 分）；
3. **制定草稿**：
   - 可通过中间的聊天框与 Agent 对话交互，输入具体的考查要点让 Agent 建议等级；
   - 也可直接点击右侧面板的 **“人工编辑”**，手动添加评分项目（Criteria）、分值上限与评分等级（Levels）；
4. **校验与准备冻结**：
   - 点击右下角 **“校验并准备冻结”**；
   - 系统将自动核对分值闭环（如各项目分值之和是否精确等于总分、等级区间是否连续等）；若有不符合项，页面会给出明确的中文修改指引；
5. **确认冻结**：
   - 校验通过后，点击 **“确认冻结为正式版本”**（v1）。冻结后评分标准具备不可变性，后续批改将严格以此为法律基准。

### 4.4 单份作业批改与交互
1. 从左侧导航进入 **“作业批改”**；
2. 选择对应的冻结评分标准，点击 **“+ 上传作业”**；
3. 选择学生提交的文件（支持 `.docx`、`.pdf`、`.md`、`.pptx` 及图片）并输入姓名与学号（也可依赖文件名自动识别）；
4. 系统自动通过后台 Docling 转换服务将作业转换为规范 Markdown，并提取插图至附件目录；
5. 转换完成后，系统自动或由教师触发运行批改；
6. 批改完成后，右侧面板展示程序计算的总分、置信度以及各细项得分与依据；
7. 若模型把握不足或依据不充分，右侧会展示醒目的 **“需要教师复核并逐项确认”** 警示框；
8. 教师可点击 **“人工修订评分项”** 修改得分，填写 **“复核备注”** 后正式确认。

### 4.5 批量作业批改与并发工作台
针对班级几十至上百份作业，使用批量批改：
1. 从左侧导航进入 **“批量批改”**；
2. 选择冻结评分标准，输入批次名称，设置并发工作数（推荐 2–4）；
3. 一次性多选待批改的学生作业文件，点击 **“创建上传草稿”**；
4. 系统为每份文件独立处理转换与身份提取；若有个别学生缺少学号，可在列表中单独补填身份，其余成功的作业不受影响；
5. 点击 **“创建正式批次”** 并点击 **“启动批改”**，后台队列将并发执行流水线批改，进度条实时更新；
6. 批改完成后，点击 **“Review”** 进入批次复核双栏工作台；
7. 教师左侧切换学生，中间对照阅读报告原文，右侧核对评分结果并勾选确认复核原因，输入复核备注；
8. 复核确认后，返回批量列表，点击 **“导出班级 CSV”**，下载包含学生信息、各项得分与复核记录的完整成绩单表格。

## 5. 常见问题排查与用户恢复路径

| 现象 | 可能原因 | 恢复指引 |
|---|---|---|
| 提示“无法连接本地服务” | 启动黑底控制台窗口被关闭或端口被占用 | 检查黑底窗口是否仍在运行；若已退出，重新双击 `start.bat`。刷新浏览器页面。 |
| 答疑输入框禁用并提示未发布资料 | 当前所选课程尚未创建并发布 active release | 进入“课程资料库”，选择该课程，点击“导入资料”并点击“发布并启用”。 |
| 评分表校验显示“分值之和不等于总分” | 人工编辑时修改了某项分值上限导致总和不一致 | 点击“人工编辑”，调整各项目的分值上限，使总和严格等于评分表总分后再点击校验。 |
| 转换提示“转换服务暂时不可用” | Docling 子进程初始化慢或被安全软件拦截 | 原始报告已完整保留；等待启动窗口稳定后，点击卡片上的“重试转换”，或直接上传 Markdown 格式报告。 |
| 批量批改中有学生进入“需要教师回答” | 作业正文缺损严重或无法识别题目 | 在该学生操作列点击“回答”，输入教师指导意见，或直接进入 Review 手动判定。 |
