## 一、发现的功能与逻辑问题

### 1. 评分表 0 条封顶规则仍触发后端必填校验阻断（单份/批量均受影响）
- **现象**：当冻结评分表的条件总分封顶规则为 `0` 条时，单份批改 Agent 在调用「更新批改草稿」时连续被校验报错 `每个封顶规则都需要明确决定` 阻断保存；必须由教师在对话中显式告知“本评分表共有 0 条条件总分封顶规则”后才通过（截图：[22-single-grading-cap-bug.png](../screenshots/2026-11-25-manual/22-single-grading-cap-bug.png)）。批量批改中「赵磊」也因模型无法判定不存在的封顶规则而停在「等待教师」状态。
- **影响**：高。无封顶规则是常见场景，会直接阻塞正常批改流程。

### 2. 批次复核工作台无法查看与回复「等待教师」的提问
- **现象**：当批量作业中有学生处于「等待教师」状态时，点进「批次复核工作台」虽显示「等待教师 / 异常(1)」，但既不展示 Agent 的提问内容，也没有回复输入框，「重试」按钮也处于禁用状态；教师必须退回「批量作业批改」列表页才能看到行内提问与回复框。
- **影响**：中。教师在复核工作台发现异常后无法就地处理，只能返回列表页。

### 3. 单份批改中途“评分结果”面板与状态栏不同步
- **现象**：批改 Agent 在「待教师回答」前的对话中已给出暂定分数，但「评分结果」面板全程显示「尚无评分结果」；教师回复澄清并进入下一轮处理后，顶部状态角标仍长时间停留在「待教师回答」，容易让教师误以为回复未提交。

### 4. 批量批改期间轮询接口偶发 HTTP 500 报错且错误提示滞留
- **现象**：在回复赵磊并触发 CSV 导出期间，`GET /api/grading/batches/{batchId}` 偶发返回 `HTTP 500`，页面顶部持续显示错误横幅「操作未完成。请保留当前内容后重试；若仍失败，请重新启动应用并再次打开该页面。」，后续轮询恢复 200 后该错误提示仍滞留不消。

### 5. 单份批改思考过程流式文本格式异常
- **现象**：Agent 思考阶段直接流式输出英文思考文本，且部分句子间缺少空格，影响阅读体验。

## 二、发现的顶栏布局、遮挡与响应式体验问题（1280×800 视口）

### 6. 单份批改页顶栏换行与下拉框版本号截断（含用户实测反馈）
- **现象**：在单份批改页面，顶栏右侧「评分标准」下拉框与「导出 CSV（6列）」按钮容易发生两行折行（用户复现并反馈）；且「评分标准」下拉框过窄导致 `· v1` 等版本后缀被截断隐藏，教师无法直接确认当前选用的冻结版本号（截图：[12-single-grading-topbar-issue.png](../screenshots/2026-11-25-manual/12-single-grading-topbar-issue.png)）。
- **关联文案矛盾**：未选评分标准时，新建批改会话卡片提示「评分标准：请先在左侧选择」，但评分标准下拉框实际位于**右上角**而非左侧。

### 7. 左上角固定悬浮 `☰` 导航按钮多处遮挡正文
- **现象**：在评分量表、单份批改、批量批改及批次复核工作台向下滚动时，左上角固定悬浮的 `☰ 打开工作台导航` 按钮会直接压住页面标题首字、快捷选项按钮、历史批次标题或「本批次会话（4/4）」文字（截图：[09-rubric-agent-dialogue-r3.png](../screenshots/2026-11-25-manual/09-rubric-agent-dialogue-r3.png)）。

### 8. 批次复核工作台右上角 Toast 遮挡导航与操作按钮
- **现象**：点击「确认」或「确认并继续下一份」后，右上角弹出的绿色成功通知条直接覆盖「上一份」「返回批量批改」等按钮，导致点击触发遮挡报错，需手动关闭 Toast 或等待消失。

### 9. 跨页面跳转后未自动滚动回顶部
- **现象**：从「评分量表」点击「前往单份批改」、切换至「批量批改」或在「批次复核工作台」切换学生后，滚动条保留原页面位置，导致新页面顶栏（标题、评分标准选择、返回按钮）位于视口上方不可见区域。

### 10. 1280×800 下双栏退化为上下堆叠且“左侧/右侧”文案失效
- **现象**：在「评分量表」「单份批改」「批次复核工作台」中，1280px 宽度下预览/结果面板均被挤到下方（首屏不可见），但文案仍写「可在右侧预览完整量表」「与右侧至少填一项」；复核时需频繁上下大跨度滚动。

### 11. 批量批改表格列宽失衡与横向溢出
- **现象**：1280px 视口下批量列表「分数」列右侧边缘被裁剪、「操作」列溢出需横向滚动；当某行出现长段「等待教师」提问时，前序列宽被严重挤压，「作业」列折成每行 2 字、「成绩已确认」徽章被压成竖排（截图：[19-batch-list-zhao-question.png](../screenshots/2026-11-25-manual/19-batch-list-zhao-question.png)）。

### 12. 课程答疑窄屏侧栏锁死导航
- **现象**：视口变窄后再恢复 1280×800 时，课程答疑左侧「答疑会话」抽屉保持覆盖态且无关闭按钮，直接挡住左上角 `☰` 按钮导致无法通过 UI 切回其他页面。

## 三、文案与细节体验建议

1. **新建课程**：目前仅支持输入课程名称，且输入框 placeholder「输入新课程名称，例如：数据结构」末尾「构」字在默认宽度下被截断；建议支持可选课程代码/学期描述并加宽输入框。
2. **课程资料库**：暂无「在线新建空白 Markdown 文档」按钮，必须先本地上传后才能在线编辑；三栏布局在 1280px 下偏窄，列表最后一项的 `...` 菜单易被容器底部裁剪。
3. **评分量表第 1 步**：已在课程资料库发布 2 篇资料，但此处默认显示「0 份参考资料」，未提示需手动勾选或自动关联。
4. **单份批改空状态与弹窗**：
   - 0 条会话时顶栏提示「会话状态已恢复；不会自动重新调用模型」略显突兀；
   - 空状态支持格式文案漏写 `TXT`（弹窗中实际支持 TXT）；
   - 新建批改会话弹窗在 1280×800 下底部「取消 / 创建会话」按钮略微溢出视口，且「转换完成后自动开始批改」默认未勾选，建议默认勾选或更醒目。
5. **批量批改**：
   - 上传区「单批最多 120 份」末尾「份」字孤立换行；
   - 列表中部分学生有快捷「确认」按钮而部分没有（因需勾选注意事项），建议增加图标或悬浮提示说明原因；
   - 批改启动后，顶栏副标题仍停留在「正式批次已创建，点击“启动批改”开始并发评分。」，未随实际进度更新。
