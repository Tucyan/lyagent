# Windows Release 前端状态同步实机验收表

## 验收准备

使用新构建的 Windows Release，不复用旧压缩包。建议准备：

- 一套“人工智能导论”课程资料，至少包含两篇 Markdown，便于快速切换文件。
- 一份可正常识别身份的单份报告。
- 六份不同学生报告，其中至少一份文件名不符合身份格式，用于补填身份。
- 一份引用 `assets/` 图片的 Markdown 及对应 PNG/JPEG；另复制一份但故意移除图片，用于制造可恢复失败。
- 两个评分表设计会话或两门课程，用于验证快速切换时旧请求不会串页。
- 一个可让名称识别或批改持续数秒的真实模型配置，以便观察“正在…”状态。

验收过程中不要只看最终结果；重点观察点击后的即时反馈、切换期间是否闪回旧内容、刷新后能否恢复，以及失败后按钮是否恢复可用。
