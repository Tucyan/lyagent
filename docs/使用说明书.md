# Course Agent 使用说明书

> 更新日期：2026-11-25  
> 适用范围：Course Agent 当前版本教师端 Web 工作台（`http://localhost:5173/`）  
> 示例课程：《Python 数据分析与可视化》

Course Agent 是一款面向课程教学与作业批改的本地 AI 辅助系统，核心流程遵循 **“教师确认发布 / 冻结 / 复核”** 原则：
1. **课程资料**须经教师确认**发布**后，课程答疑才能检索使用；
2. **评分量表**须经教师校验并**冻结**为正式版本后，方可用于作业批改；
3. **AI 批改结果**均需由教师**复核确认**后，才计入正式成绩导出。

## 1. 首页总览与新建课程

1. 启动本地服务后，在浏览器打开 `http://localhost:5173/` 进入**课程总览**页面。确认页面顶部或模型状态显示「AI 助教已就绪」（若未配置模型，请先点击左下角**模型设置**完成配置）。

![课程总览初始页](screenshots/2026-11-25-manual/01-course-overview.png)

2. 在课程名称输入框中填写新课程名称（例如：`Python 数据分析与可视化`），点击创建按钮即可生成课程并自动进入该课程工作区。

![新建课程后进入课程工作区](screenshots/2026-11-25-manual/02-course-created.png)

> **提示**：左侧导航栏包含「课程总览」「课程资料库」「课程答疑」「评分量表」「单份批改」「批量批改」及底部的「模型设置」。在窄屏或小窗口下，左侧导航可收起，通过左上角 `☰` 按钮重新展开。

## 2. 课程资料导入、编辑与发布

课程资料采用 **“修订草稿 → 发布启用”** 机制。未发布前，草稿内容不会影响线上课程答疑。

1. 在左侧导航点击**课程资料库**，上传本地教学文件（支持 Markdown、TXT、PDF、DOCX 等格式；注意 PDF/DOCX/PPTX 依赖本地文档解析服务就绪）。
2. 导入后系统自动创建修订草稿（如 `v1`），可在界面中直接查看文档目录、编辑 Markdown 源码并实时预览排版效果。

![课程资料草稿编辑与预览](screenshots/2026-11-25-manual/03-knowledge-draft-editor.png)

3. 核对资料无误后，点击**发布并启用**并在确认弹窗中点击**确认发布**。发布完成后，状态将更新为「当前使用 v1 · X 篇资料」，此时课程答疑即可基于该版本资料作答。

![知识库发布 v1 后状态](screenshots/2026-11-25-manual/04-knowledge-published-v1.png)

## 3. 课程答疑与原文引用核查

1. 进入**课程答疑**页面，系统会根据已发布的课程资料自动生成推荐提问。
2. 在输入框输入课程相关问题（例如：“实验一中 AQI 超标天数按什么阈值计算？时间序列缺失值建议怎么处理？”）并发送。
3. AI 助教仅依据当前**已发布（active）**的知识库版本作答，并在回答底部附带精确到文件与行号的引用标签（如 `02-Pandas数据清洗参考指南.md · L4–L12`）。

![课程答疑回答与引用标签](screenshots/2026-11-25-manual/05-course-qa-answer.png)

4. 点击任意引用标签，右侧会滑出原文抽屉并定位到对应行段，方便教师或学生核对依据。

![点击引用查看原文抽屉](screenshots/2026-11-25-manual/06-course-qa-citation-drawer.png)

## 4. 评分量表创建与 Agent 对话共创

批改作业前，必须先创建并冻结一份评分量表。

1. 进入**评分量表**页面，按向导第 1 步填写评分标准名称（如 `实验一：城市空气质量分析评分标准`）、总分（如 `100`）及作业要求，并可关联已发布的课程参考资料。

![评分量表第 1 步填写作业信息](screenshots/2026-11-25-manual/07-rubric-step1-info.png)

2. 选择评分方式（如「加分制」）并生成初稿后，系统会进入“对话共创 + 量表预览”工作台。

![评分量表初稿 v1](screenshots/2026-11-25-manual/08-rubric-agent-draft-v1.png)

3. 教师可通过多轮对话与评分 Agent 反复打磨细则，例如：
   - **细化分项与档位**：要求将某维度细化为优秀/良好/及格/不及格等档位，并明确常见错误（如直接 `dropna()`）的得分上限；
   - **边界与冲突检查**：追问特定边界情况（如“只画了 1 张完整图表归哪一档？各档位间是否存在重叠或遗漏？”），Agent 会自动审查区间连续性与规则冲突并给出修订方案；
   - **确认修改**：采纳合适方案后，Agent 自动更新草稿版本（如连续区间 0.5 分步长）。

![与评分 Agent 进行多轮边界评审对话](screenshots/2026-11-25-manual/09-rubric-agent-dialogue-r3.png)

![采纳建议后更新为草稿 v4](screenshots/2026-11-25-manual/10-rubric-agent-refined-v4.png)

4. 确认各分项总和与档位边界无误后，依次点击**校验并准备冻结** → **确认冻结为正式版本**。冻结后的量表状态变为不可变正式版本（如 `v1`），即可在批改模块中选用。

![评分标准冻结为正式版本 v1](screenshots/2026-11-25-manual/11-rubric-frozen-v1.png)

## 5. 单份作业批改与确认

单份批改适合在正式批量批改前试跑样卷，或对个别学生作业进行单独精批。

1. 进入**单份批改**页面，先在页面右上角「评分标准」下拉框中选择已冻结的量表版本，然后点击左侧**上传作业**打开「新建批改会话」弹窗。

![单份批改页顶部评分标准选择](screenshots/2026-11-25-manual/12-single-grading-topbar-issue.png)

2. 选择学生作业文件（支持 Markdown、TXT、DOCX、PDF、PPTX 与图片；按 `学号_姓名_作业名` 命名时可自动识别学生姓名与学号）。若希望文件解析后立即开始 AI 评分，请勾选底部的**转换完成后自动开始批改**，再点击**创建会话**。

![新建单份批改会话弹窗](screenshots/2026-11-25-manual/13-single-grading-new-session.png)

3. 若批改过程中 Agent 遇到无法自行裁决的情况（例如报告仅文字描述图表而未附图片），会暂停并进入**待教师回答**状态，给出选项或输入框等待教师指示。

![单份批改待教师回答澄清](screenshots/2026-11-25-manual/14-single-grading-pending-question.png)

4. 批改完成后，界面展示总分、各维度得分、置信度及具体扣分/得分理由。教师核对各复核提示并填写复核备注后，点击**确认并发布正式结果**，系统将生成结果校验哈希并将状态更新为「已确认」。

![单份批改结果详情](screenshots/2026-11-25-manual/15-single-grading-result.png)

![单份批改确认后状态](screenshots/2026-11-25-manual/16-single-grading-confirmed.png)

## 6. 批量作业批改、复核与 CSV 导出

批量批改支持同时上传多份学生作业并发评分，并集中复核与导出成绩。

1. 进入**批量批改**页面，选择冻结的评分标准，一次性选择多份作业文件上传。系统会自动校验文件格式与学生身份信息，待全部显示**已就绪**（如 `4/4`）后，点击创建正式批次。

![批量批改 4 份作业上传就绪](screenshots/2026-11-25-manual/17-batch-upload-ready.png)

2. 点击**启动批改**，系统按并发数（如并发 4）开始批改并实时展示进度。

![批量并发批改进行中](screenshots/2026-11-25-manual/18-batch-running-progress.png)

3. 若批改过程中个别作业触发「等待教师」提问，可在批量列表页该学生行内直接查看问题并输入回复，提交后系统会自动继续完成该份作业的批改。

![批量列表行内回复等待教师的提问](screenshots/2026-11-25-manual/19-batch-list-zhao-question.png)

4. 批改完成后，点击进入**批次复核工作台**，逐份对照学生报告原文、各维度得分与分析依据，勾选复核事项并确认成绩。

![批次复核工作台核查详情](screenshots/2026-11-25-manual/20-batch-review-detail.png)

5. 全部或部分作业确认后，返回批量列表页即可分别导出：
   - **已确认成绩 CSV**：仅包含教师已正式确认的成绩；
   - **处理汇总 CSV（含待复核）**：包含当前批次所有作业的处理状态与分数，便于跟踪进度。

![全部 4 份作业成绩已确认状态](screenshots/2026-11-25-manual/21-batch-all-confirmed.png)

## 7. 常见问题与注意事项

1. **文档解析服务不可用**：上传 PDF、DOCX 或 PPTX 时，请确保本地 Docling 文档转换服务已正常启动；纯 Markdown（`.md`）与纯文本（`.txt`）不依赖外部转换服务。
2. **关于条件总分封顶规则**：若评分量表未设置「条件总分封顶」规则（即 0 条），在极少数情况下批改 Agent 可能在保存草稿时反复校验封顶规则或停在「等待教师」状态；此时在对话中直接回复“无封顶规则限制，按各档位正常打分即可”即可继续。
3. **1280px 宽度下的界面操作提示**：
   - 在较窄屏幕下，评分预览与批改结果面板可能位于对话框或报告下方，如未在首屏看到结果，请向下滚动页面；
   - 确认成绩后右上角弹出绿色通知条时，可先点击通知条上的 `×` 关闭，再点击其后方的「返回」或「上一份」按钮。
4. **成绩正式生效规则**：所有 AI 生成的分数与评语均属于辅助建议，只有经过教师点击确认后的结果才会写入正式成绩 CSV。
