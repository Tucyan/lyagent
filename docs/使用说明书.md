## 启动与首页

1. 使用 Windows 发布包时，运行包内的 `start-course-agent.bat`，启动器负责启动本地工作台和 Docling 转换服务。使用源码时，按本地开发指南分别启动服务，并打开终端显示的工作台地址。 [本地开发指南](../.docs/development.md)
2. 如果首次打开进入模型配置页，填写主模型的服务商、模型、服务地址和 API Key。先点「测试连接」，通过后点「保存设置」，按页面提示返回工作台。进入工作台后可从左侧底部打开「模型设置」。
3. 首页是「课程总览」。右上角「AI 助教已就绪」显示模型配置状态。左侧「当前课程」用于切换课程。中间的课程卡片显示生效讲义、答疑对话、评分标准和批改数量。下方的流程卡片可直接打开资料库、答疑、评分量表、单份批改、批量批改和成绩导出。

![教师工作台首页全页，展示课程管理、侧栏和业务入口](screenshots/2026-11-28-manual/01-teacher-home.png)

## 新建和切换课程

1. 在「课程总览」的「课程管理」右上方填写课程名，例如「校园食堂减废实训」，再点「新建课程」。
2. 创建后查看课程卡片上的「当前课程」及左侧课程选择器。切换已有课程时，可用左侧下拉框，也可点对应卡片上的「设为当前课程」。
3. 从首页或侧栏进入下一项工作前，核对左侧课程名。

![在课程管理右上方填写新课程名称](acceptance/2026-11-28-teacher-workbench/screenshots/01-create-course-input.png)

![新建课程被选为当前课程](acceptance/2026-11-28-teacher-workbench/screenshots/02-course-created.png)

## 导入并发布课程资料

1. 打开「课程资料库」，确认页首的课程名，再点「导入资料」。课程资料库接收 Markdown（`.md`），可以一次选择多份文件。选择「食堂称重与数据记录」和「减废干预与成效复盘」两份讲义。
2. 等待「修订草稿」生成。逐篇点选左侧文件，在中间核对或编辑 Markdown，在右侧查看实时预览。有修改时点击「保存修改」。
3. 点「发布并启用」，在弹窗中选「确认发布」。切到「当前版本」，检查版本号和文档列表。答疑随后可以检索当前生效版本。

## 课程答疑与引用核查

进入「课程答疑」后点「新建对话」。发送前检查输入框旁的「联网搜索」。关闭此开关时，课程资料检索仍可使用，生成回答仍会调用已配置的模型。

1. **课程资料内的问题。** 关闭「联网搜索」，询问「两次称重净剩余共 4.00 kg、餐盘共 50 只，每盘平均剩余量是多少？」确认回答为 80.0 g/盘。点击答复底部的资料引用，核对文件名、行号和原文。

![关闭联网搜索后输入课程计算题](acceptance/2026-11-28-teacher-workbench/screenshots/12-qa-offline-input.png)

![回答显示公式、结果与课程来源](acceptance/2026-11-28-teacher-workbench/screenshots/13-qa-offline-result.png)

![点击课程来源定位到公式所在行](acceptance/2026-11-28-teacher-workbench/screenshots/13b-qa-offline-citation.png)

2. **需要公开资料的问题。** 打开「联网搜索」，说明希望核查的来源。例如询问美国环保署 Wasted Food Scale 将源头减量与堆肥如何排序。回答完成后点「网络来源」，在浏览器打开发布机构的原网页。

3. **遇到越权请求或证据不足。** 请求跨课程披露学生姓名、学号和成绩时，答疑拒绝披露。询问讲义未记载的正式批准文件及发布日期时，答疑标明「资料不足」。收到资料不足提示后，核对当前课程是否已发布相应讲义，或使用可访问的公开权威来源。

## 创建和定稿评分量表

1. 进入「评分量表」，点「新建评分表」。填写评分标准名称和满分，再填写作业要求或导入参考草稿。作业 A 设为 100 分，要求核查称重记录、复算净重与每盘指标，并评价复核建议。
2. 点「下一步：选择评分方式」，按作业要求选择「加分制」「减分制」或「混合制」，再点「选择并开始」。等待 Agent 生成草稿，在右侧核对满分、评分项目和各分档。

### 人工修改

点击「人工编辑」，找到要改的评分项目并展开。修改相应的「达成条件」、分数或档位，再点「保存人工修改」。作业 A 更新了「称重时段记录」的满分条件，要求同时写明日期、午餐起止时间和回收点。保存后检查草稿版本和右侧预览。

![人工修改称重时段记录的达成条件](acceptance/2026-11-28-teacher-workbench/screenshots/22-rubric-a-manual-edit.png)

### 与 Agent 共创

作业 B 使用混合制，适合将基础分、额外奖励与条件总分上限写在同一量表中。

1. 第一轮先询问规则的合理性。如「请先解释，暂时保留当前草稿。缺少干预前餐盘数时封顶 70 分是否合理？奖励可以突破上限吗？」核对 Agent 的解释及右侧草稿版本。
2. 第二轮明确要求修改并保存。例如「只有缺少可核查的基线餐盘数、也没有同期同地点的独立基线记录时才封顶 70 分。奖励先算，再应用封顶。」核对更新后的规则和版本。

### 冻结为正式版本

核对分数、分档和扣分边界后，先点「校验并准备冻结」，再点「确认冻结为正式版本」。看到「当前评分表已定稿」后，就可以使用正式版本批改。后续需要修改时，从已定稿版本创建修订草稿，再完成一次校验和冻结。

## 单份作业批改

1. 在「单份批改」确认当前课程和评分标准版本，点「＋ 上传作业」。填写姓名、学号和作业名，再选择一份报告。报告支持 Markdown、TXT、DOCX、PDF、PPTX 和常用图片。DOCX、PDF、PPTX 需要 Docling 就绪。Markdown 引用了本地图片时，可在表单中选择对应的 `assets` 目录。
2. 勾选「转换完成后自动开始批改」，点「创建会话」。如果希望先检查转换文本，可保留未勾选状态，确认正文后再点「开始批改」。出现「等待教师」时，阅读问题，提交判断依据并选择「回答并继续批改」。
3. 批改结束后，在「学生作业」与「评分结果」之间切换，对照原文、各项分值、理由与置信度。需要改分时用「人工修订评分项」。按页面提示勾选复核原因并填写备注，然后点「确认并发布正式结果」。
4. 在会话列表确认「成绩已确认」，并在评分结果面板检查正式结果哈希。需要单份文件时，可在已确认会话中使用 JSON 或 Markdown 导出。

## 批量作业批改

1. 打开「批量批改」，点「＋ 新建批改批次」。选择对应的冻结评分标准，填批次名，再用「选择学生报告」上传一组文件。可在「更多设置」里检查计划使用的并发数。
2. 点「下一步：上传并准备批次」。核对文件对应的姓名与学号，等要批改的全部作业显示「已就绪」。身份识别有误时，在这一阶段按页面提示补填并保存，或替换对应文件。
3. 点「创建正式批次」，再点「启动批改」。进度表会显示排队中、批改中、待复核或失败等状态。如需暂缓，点「暂停领取」，已运行任务可继续结束。

![选择作业 A 的评分标准和六份学生报告](acceptance/2026-11-28-teacher-workbench/screenshots/35-batch-a-selected.png)

![准备完成，六份报告身份与状态可核对](acceptance/2026-11-28-teacher-workbench/screenshots/36-batch-a-ready.png)

4. 点击「进入复核」。左边切换学员，中间看报告，右边核对得分、理由和注意事项。按提示填写备注并确认，可用「确认并继续下一份」连续处理。
5. 回到批量工作台，核对批次状态和已确认数量。示例中的 A、B 两个批次均显示「本轮已结束 · 已确认 6/6 份」。

## 预览与导出成绩

1. 从左侧「成绩导出」进入，在「导出维度」选择统计方式。

   | 导出维度 | 选择对象与用途 |
   | --- | --- |
   | 按批改批次 | 选择一次批次。「仅已确认成绩」用于班级正式成绩，「含待复核汇总」用于查看处理进度。 |
   | 按评分标准 | 选择冻结标准及版本，合并该标准下的已确认单份和批量成绩。 |
   | 按学生导出 | 选择某位学生，汇总其在当前课程下的已确认作业。 |

2. 选择导出对象，核对「成绩统计概览」和「导出数据预览」。可按关键词或分数筛选，用「导出列设置」决定需要的列，并勾选要导出的记录。
3. 确认按钮中的条数满足预期，再点「确认下载 CSV」。在本课程中按作业 A 或作业 B 的正式标准导出，各显示 8 条已确认成绩。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 首次打开需要模型设置，或答疑提示连接异常 | 打开「模型设置」，确认服务商、模型和地址后点「测试连接」，按页面反馈处理。 |
| 讲义已经上传，答疑仍提示资料不足 | 核对当前课程，并到「课程资料库」确认讲义已出现在「当前版本」中。 |
| 开了联网仍无法引用某个网址 | 检查提供的来源能否打开。网页阅读有正文大小限制，优先使用同一机构的简明原文页面。 |
| DOCX、PDF 或 PPTX 一直等待转换或转换失败 | 检查 Docling 就绪状态与工作台内的具体提示。转换完成后，先核对正文再进入评分。 |
| 不能确认成绩，或成绩没有出现在正式导出预览 | 查看是否还有复核项未勾选、备注未填，或会话仍为待复核。确认后再刷新预览。 |
| 在源码环境启动时出现 SQLite 模块加载错误 | 核对实际 Node.js 版本与原生模块 ABI。 [Windows 启动记录](../AGENTS.md#修改维护与验证) |
